Политика конфиденциальности

Дата обновления: 9 октября 2026 года

1. Общая информация

Euphoria Monopoly — развлекательное приложение для Discord, предназначенное для игры в настольную игру «Монополия» в сообществе Euphoria.

2. Используемые данные

При запуске игры пользователь может каждый раз заново вводить или выбирать имя и аватарку для отображения своего игрового профиля. Эти сведения используются для представления игрока в интерфейсе игры.

3. Хранение данных

Если введённые имя и аватарка используются только в текущей игровой сессии, они не сохраняются приложением после её завершения. Если функциональность приложения предусматривает сохранение профилей, игровые данные или их передачу серверу, сведения об этом должны быть отражены в настоящей политике до начала такой обработки.

4. Передача третьим лицам

Приложение не предназначено для продажи персональных данных или их использования в рекламных целях. Discord и используемые технические сервисы могут обрабатывать данные в соответствии со своими собственными условиями и политиками.

5. Безопасность и права пользователей

Мы стремимся ограничивать обработку данных тем, что необходимо для работы игры. Пользователь может прекратить использование приложения в любое время. Обращения по вопросам конфиденциальности можно направлять администрации сервера Euphoria.

6. Изменения политики

Политика может обновляться при изменении функциональности приложения. Актуальная версия публикуется на этой странице.

Условия использования

Дата обновления: 9 октября 2026 года

1. Назначение

Euphoria Monopoly — развлекательная игра для пользователей Discord. Приложение не является финансовым сервисом.

2. Игровые элементы

Игровые деньги, имущество, балансы и прочие внутриигровые объекты, если они предусмотрены, предназначены для игрового процесса и не являются реальными денежными средствами.

3. Правила поведения

  • Не использовать ошибки игры для нарушения игрового процесса.
  • Не пытаться нарушать работу приложения или получать несанкционированный доступ к данным.
  • Не использовать приложение для мошенничества или причинения вреда другим пользователям.
  • Соблюдать правила Discord и сообщества Euphoria.

4. Доступность

Приложение может временно быть недоступно из-за технического обслуживания, обновлений или неисправностей. Непрерывная работа не гарантируется.

5. Ответственность

Приложение предоставляется для развлечения. Это условие не отменяет прав пользователей, которые защищены применимым законодательством.

6. Интеллектуальная собственность

Название Euphoria Monopoly само по себе не означает официальной связи с Discord или правообладателями оригинальной настольной игры. Использование материалов должно соответствовать правам их владельцев.

7. Обновление условий

Условия могут обновляться при изменении приложения. Продолжая использование приложения после публикации обновлений, пользователь использует его с учётом действующих условий в пределах, допускаемых законом.

8. Контакты

По вопросам использования приложения можно обратиться к администрации Discord-сервера Euphoria.
